## 一句话

**【一句话】**把配比搜索从"数据空间"搬进"参数空间"：每个域只训一个短专家，候选配比不训练、直接按配比把专家权重加权合并成一个新模型去考试——一阶近似下两者等价，工业级 mid-training 验证超人工调参、成本降 100×。

## 方法机制（四步，全程无一次全量配比训练）

1. **训短专家**：从同一预训练基座出发，K=4 域（沿 #74 Nemotron 四域划分：math/code/SFT/web）各训一个专家，每个只吃 5B token = 试验预算 200B 的 **2.5%**
2. **task-vector 合并**：候选配比 α → `Θ_merge(α) = Θ_base + Σ α_k·(Θ_k − Θ_base)`。纯逐元素算术，秒级；得到的是一个**普通的单模型**（非 ensemble、非多模型投票），可直接推理评测
3. **学性能面**：单纯形上采 **N=40** 个种子点（粗网格+启发式先验），每个 merge 出来真跑一遍 benchmark，训 LightGBM 回归器（每能力一个）拟合"配比→分数"面。**40 个种子点是回归的训练数据**（40 对 α→真分数）；单纯形上其余任意候选全部由拟合好的函数**预测**打分（零成本）——与 RegMix"proxy runs 训 LightGBM"完全同构，只是数据点生产方式从 proxy 训练换成 merge+推理
4. **细搜+验证**：在学到的面上细粒度搜 α*，把 α* 真 merge 出来再评一次确认

**成本结构**：总成本 ≈ K·D_expert·C_train + N·C_benchmark_eval。专家训练是唯一训练开销；benchmark 评测次数被回归面从"每候选一次"压到"40 个种子点一次"。

## 理论保证的精确含义（全文最值得咀嚼的部分）

Taylor 展开对比两条轨迹的终点参数：

- **真混合训练**（配比 λ）：一阶项 `Σλ_k·g_k` + 二阶项 `Σ_{k,j} λ_kλ_j·H_k·g_j`（**含全部交叉项**）
- **权重合并**（α=λ）：一阶项**完全相同** + 二阶项只剩对角 `Σλ_k·H_k·g_k`

三个推论：
- **一阶完全一致**是 merge 能当 proxy 的理论根基
- **误差恰好=跨域交互项**（域 j 的梯度被域 k 的曲率扭曲）——专家训练越短（ηT 小）近似越好，**专家只训 2.5% 预算不是抠门，是理论要求**
- 交互保真度排序：真训练 > MergeMix（有二阶对角项）> MDE loss 线性加权（纯一阶）；成本排序正好反过来

## 证据链（四层，每层回答一个质疑）

1. **前提成立吗**——math/code 双域受控：各训 25B token 专家，权重插值 Θ_α vs 真实混合数据训练 D_λ，性能趋势对应（合并曲线≈混合训练曲线）
2. **代理可信吗**——12 个配比做**全量真 mid-training** 对照：合并预测排序 vs 真训排序 Spearman ρ>0.9（知识类 **0.98**）
3. **真比人强吗**——8B/16B MoE（各 1.4B 激活）工业级 mid-training：基线=均匀/人工调参（**已上线生产**）/Adapted RegMix（#36），MergeMix 持平或超过，math/code/reasoning 明确增益、其余域近无损，搜索成本降 **100×**
4. **换规模还行吗**——8B 搜出的配比**直接用于 16B mid-training 仍超人工基线**（2× 容量差下配比可迁移）

### 逐层挑刺（2026-10-13 讨论记录）

- **受控层**：作者自述选了"已知强相关"的 math/code 域对——友好案例做演示，真正考验在保真层
- **保真层**：12 配比 ρ>0.9 是**全位次**相关，不保证 top-2/3 局部排序正确（分数接近时小误差即换位——而实际决策只关心头部）；math 单项 ρ 未单列
- **工业层**：混淆①人工基线"已部署于**上一个**内部旗舰模型"——未必为本次 8B/16B 设定充分重调过；混淆②内部 benchmark 无法外部复核
- **跨尺度层**：n=1（单一尺寸对、单方向迁移），无误差棒

总评：内部自洽、分层合理，但全部自报、无外部复现、MoE 单栈——**方向可信，数字别引**。

## 五个附加发现

- **静态够用**：50% 训练进度处用中间 checkpoint 重搜配比 ≈ 初始结果——"最优配比是 mid-training 任务的稳定内在属性"，一次静态搜索足够（与 #36/#66 动态线张力：那些是预训练全程设定，这是短 mid-training 阶段）
- **math 最优点在混合区不在纯 math**：code 地形正交（最优≈纯域），math 最优需要 math+SFT+web 协同（"推理是复合能力"）——r<1.0 证据链新成员（连 #113/#14/§28）
- **层级搜索**：4 粗域→16 细簇（Math 细分 Web Math/Math QA/Synthetic Study Notes/Formal Math；Web 细分 EN/CN/Books/Wikipedia/Academic Papers），top-down 先粗后细，全自动〈MM,MM〉超全手工
- **AdamW**（β₁=0.9/β₂=0.95/wd=0.1）——与用户 nanochat-npu 栈同优化器（#126 是 Muon，此篇迁移条件更好）
- **恒定 LR+merge 最佳 16 checkpoints 模拟 annealing**（WSM schedule）——merge 不只用于搜索，还用于模拟退火段

## 对用户场景的落地推演（Mini-MergeMix 草稿）

**可行性**：task arithmetic 是 dense 模型起家的技术（Wortsman model soups 一系），MoE 非必要条件。

- 从 ClimbLab 基座出发训 3 个短专家（math/代码或其他/web），各 ~100-150M token——1.8B 预算内可承受，或用扫 r 时的极端 run 兼任专家
- 40 个种子点 = 40 次 merge+STEM accuracy 直评——**评估成本就是本来要做的 benchmark 推理，零额外训练**
- LightGBM 学面 → 细搜 → 预测最优 r 真训一次验证
- **核心卖点**：在 1.5B 本尊上获得 >40 个配比的信息量，而只训 3-4 个短专家——绕开 400M proxy 的跨尺度外推问题（错误结构从"小模型预测大模型 loss"换成"配比最优点的尺度稳定性"）

**风险与边界**：
- **权重合并的盆地风险（2026-10-13 用户提出，讨论记录）**：合并后的模型未经任何训练，模块间数值没有重新关联——直觉上"推理链条会断"。该担心在"合并两个各自从零训练的模型"时真实成立（神经元特征互不对应，平均=乱码搀混，Git Re-Basin 一系的动机）；本文处于友好区间（同基座+短步长=同一线性连通盆地，model soups/task vectors 的经验基础），**专家必须短正是为了不出盆地**——训长后各专家漂向不同盆地，插值路径穿过高损失区。插值曲线平滑+ρ>0.9 是该风险的经验检查，但无盆地半径的理论保证
- **短专家看不到相变（2026-10-13 讨论记录）**：短专家只拍到初始梯度方向；真实训练中各域梯度会演化（快域降完、慢域接棒）。一阶近似在总步长短（mid-training）时成立，但若某域存在相变（#01），短专家看不到相变后的推动方向——**math 是相变嫌疑最大的域**。与 #68 LogFloor 同款的轨迹外推盲区
- **域间速度不平衡=忠实复制而非失真**：真混合训练的更新 Σλ_k·g_k 同样被快域主导，merge 一阶项与它逐项相等——"快域推得猛"不是 merge 引入的偏差（由 12 配比 ρ>0.9 端到端背书）
- 专家必须短（二阶交叉项误差随专家 token 数增长）——1.26B math 预算全喂专家违反设定
- 绝对分数偏低（专家欠训练），保的是**排序**不是终点性能——只可用于搜索，不可用于最终评估
- 8B→16B（2×）成功 vs #73 MAI rank non-invariance 反例：用户 400M→1.5B（3.75×）落在两者之间，无先验保证；Mini-MergeMix 在 1.5B 本尊上做则**回避**了这一问题（这是它相对 400M proxy 线的结构优势）
- 100× 是工业成本结构（省 10 次全量 run）；N=1-2 本来不做全量搜索，收益换算不能直接搬
- ⚠️ 无 venue、评测为内部 benchmark、MoE 栈（方法对 dense 适用但未在他们文中验证）
