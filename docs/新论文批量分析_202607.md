## #28 How Learning Rate Decay Wastes Your Best Data in Curriculum-Based LLM Pretraining

**arXiv:2511.18903 | Princeton+清华 | Kairong Luo, Kaifeng Lyu, Wenguang Chen**

### 核心发现

**LR decay 与 curriculum training 存在根本性冲突**：

- 在 constant LR 下，ascending curriculum（低质量→高质量）比 random 高 **+1.57%**
- 在 cosine LR decay 下，这个优势缩小到仅 **+0.60%**
- 原因：LR decay 导致高质量数据出现在训练末尾时，学习率已经过低，无法充分利用

### 两个修复方案

**方案 1：Moderate LR Decay (WSMD)**
- 将最终 LR 设为峰值的 1/5 到 1/2（而非接近 0）
- 例：peak=3e-3 → 最终 LR=6e-4 到 1.5e-3
- 预期收益：核心指标 **+1-2%**

**方案 2：Constant LR + Model Averaging (CMA)**
- 使用 warmup-constant schedule（无 decay）
- 保存最后 6 个 checkpoint
- 应用 EMA（α=0.2）或 SMA
- 预期收益：核心指标 **+2-3%**

**最佳组合 (CDMA)**：moderate decay + EMA
- 1.5B 模型：相对 improvement **+2.7%** vs Cos+Uniform
- 3.2B 模型（大规模续训练）：Core **+1.09%**，ARC-C **+3.39**，BoolQ **+3.39**

### 实验设置

| 配置 | 值 |
|------|-----|
| 模型规模 | 0.5B, 1.5B, 3.2B |
| 训练 tokens | ~50B (小模型), 884.8B (3.2B 续训练) |
| 数据集 | DCLM Baseline, WebOrganizer |
| 质量指标 | DCLM fasttext scores, PreSelect scores |
| Peak LR | 3e-3 (主实验), 1e-3 (3.2B) |
| Batch size | 2048 |
| Checkpoints for averaging | 6 |
| EMA α | 0.2 |

### 对 QuaDMix 的关键启示

**QuaDMix 的 quality-top-k 选择 + cosine LR decay 正在浪费质量信号！**

QuaDMix 当前流程：
1. ✅ Quality-top-k 选择高质量数据
2. ❌ 标准 cosine LR decay → 高质量数据被低学习率浪费

**立即行动**：
1. **最简方案**：将 cosine decay 改为 moderate decay（最终 LR = peak 的 1/3-1/2）
2. **最佳方案**：Constant LR + 最后 6 checkpoint EMA 平均
3. **进阶**：多域 curriculum（每个域内按质量排序，全局交错）

**预期收益**：ARC-C +3-4 points, MMLU +0.5-1 point, 核心平均 +1-2%

### 可信度评估

- **机构**：Princeton (Kaifeng Lyu) + 清华 (Wenguang Chen) — 顶级
- **规模**：1.5B 模型, 30B+ tokens — 足够验证
- **Venue**：arXiv (可能 ICLR'26 under review)
- **代码**：未公开
- **评级**：★★★★☆ — 发现清晰、实验充分、修复方案简单可行

## #29 MixAtlas: Uncertainty-aware Data Mixture Optimization for Multimodal LLM Midtraining

**arXiv:2604.14198 | Apple+UW+VTech | Bingbing Wen, Bill Howe, Lucy Lu Wang, Javier Movellan**

### 核心方法

**两轴分解 + GP surrogate + GP-UCB 主动采样**：

1. **Task Supervision 轴**（5 类）：Detailed Captioning, OCR, Grounded Captioning, Detection, VQA
2. **Image Concept 轴**（10 类）：CLIP ViT-L/14 embedding → k-means(10) → 人工标注
3. **Proxy 模型**：Qwen2-0.5B（与目标模型同架构族）
4. **Surrogate**：Gaussian Process（非 LightGBM）
5. **Acquisition**：GP-UCB = μ(h) + κ·σ(h)，平衡探索与利用

### 关键结果

| 设置 | Uniform | RegMix (LightGBM) | MixAtlas (GP) | 提升 |
|------|---------|-------------------|---------------|------|
| Qwen2-7B Task 轴 (5D) | 46.72 | 46.50 | **50.68** | +8.5% |
| Qwen2-7B Concept 轴 (10D) | 37.19 | 40.12 | **47.18** | +17.6% |
| Qwen2.5-7B Task 迁移 | — | 52.54 | **54.27** | +3.3% |
| Qwen2.5-7B Concept 迁移 | — | 46.76 | **47.21** | +1.0% |

**Step 效率**：达到相同 loss 所需步数减少 **50-57%**（约 2x 加速）

### GP vs LightGBM 直接对比

| 维度 | GP (MixAtlas) | LightGBM (QuaDMix/RegMix) |
|------|--------------|--------------------------|
| 不确定性量化 | ✅ 原生 σ(h) | ❌ 无 |
| 主动采样 | ✅ GP-UCB | ❌ 被动回归 |
| 样本效率 | 同预算下高 4-7 点 | 需要更多评估 |
| 可扩展性 | O(n³) 随观测增长 | 大数据集友好 |
| 高维表现 | 优势随维度增大（10D 差 7 点） | 高维退化更严重 |

### Proxy 迁移验证

- 0.5B proxy → 7B target：**成功**（+8.5%）
- 0.5B proxy → 7B 跨族（Qwen2→Qwen2.5）：**成功**（+3.3%）
- 这直接验证了 proxy-to-target 迁移假设

### 对 QuaDMix 的启示

1. **GP surrogate 可能优于 LightGBM**：同预算下高 4-7 点，且有不确定性量化
2. **但 GP 的 O(n³) 扩展性**是问题：QuaDMix 的 198 维搜索空间可能超出 GP 能力
3. **两轴分解思路**可借鉴：将 QuaDMix 的 22 域分解为 modality × domain 两个低维轴
4. **GP-UCB 主动采样**可替代 LightGBM 的被动回归+最优点选择

### 可信度评估

- **机构**：Apple（Bingbing Wen 实习期间）+ UW（Bill Howe, Lucy Lu Wang）— 较强
- **规模**：0.5B proxy → 7B target — 中等
- **Venue**：arXiv only
- **代码**：未公开
- **评级**：★★★☆☆ — 方法新颖，GP vs LightGBM 直接对比有价值，但 multimodal 场景与 QuaDMix 有差异

## #30 WebGraphMix: Pretraining Data Selection via Web Graph Centrality

**arXiv:2606.11499 | Princeton (Danqi Chen 组) | Vedant Badoni, Danqi Chen, Xinyi Wang**

### 核心方法

**完全 training-free 的数据选择信号**：利用 Common Crawl 网页图的拓扑结构

1. **Web 图构建**：Common Crawl host-level 图（13.9M 节点, 439.6M 边）
2. **中心度计算**：
   - Betweenness Centrality：衡量跨社区桥接能力（4 H100, 6 小时）
   - Katz Centrality：衡量递归影响力（1 H100, 3 小时）
3. **文档映射**：每个文档继承其 host 的中心度分数
4. **混合策略**：α × Top-K(中心) + (1-α) × Bottom-K(边缘)

### 关键结果

| 方法 | 1B 平均 | vs Random |
|------|---------|-----------|
| Random | 39.8% | — |
| Quality (DCLM-fasttext) | 42.3% | +2.5% |
| WebGraphMix (Betw. 50%) | 41.4% | +1.6% |
| **WebGraphMix+ (Betw. × Quality)** | **43.8%** | **+4.0%** |

**核心发现**：
- 中心 vs 边缘互补：1:1 混合优于任一极端
- 中心 host → 符号/算法推理 (+1.4%)
- 边缘 host → 事实知识 (+1.2%) + 常识 (+0.5%)
- **与质量信号正交**：18/18 种组合配置均超过 quality-only baseline

### 能力依赖效应

| 数据类型 | 中心 host 效果 | 边缘 host 效果 |
|----------|---------------|---------------|
| 符号推理 | **+1.4%** | +1.2% |
| 事实知识 | +0.2% | **+1.2%** |
| 常识 | -0.6% | **+0.5%** |
| 阅读理解 | -0.8% | +0.7% |

### 对 QuaDMix 的启示

1. **完全正交的新信号维度**：网页图中心度与 FastText 质量分数独立
2. **实现成本极低**：一次性 9 GPU-hours，之后零开销
3. **最佳组合方式**：乘法组合（centrality × quality）+ 50/50 中心/边缘混合
4. **预期收益**：在 quality-top-k 基础上额外 +1.5%

### 可信度评估

- **机构**：Princeton (Danqi Chen — BERT/DPR 共同作者, h-index 极高) — 顶级
- **规模**：400M + 1B, 8B + 28B tokens — 中等
- **Venue**：arXiv only
- **代码**：未公开
- **评级**：★★★★☆ — Danqi Chen 组出品，发现清晰，training-free，正交性验证充分

## #31 PreSelect: Predictive Data Selection (ICML 2025)

**arXiv:2503.00808 | HKUST+Vivo AI | Kashun Shum, Yuzhen Huang, Junxian He**

### 核心方法

**"预测能力强的数据 = 教学效果好的数据"**：
1. 用 6 个 Llama 模型计算每个文档的 "predictive strength"（模型 loss 与下游性能的相关性）
2. 训练 fastText bi-gram 分类器（900K seed set）进行大规模筛选
3. 按 predictive strength 排序选择 top 文档

### 关键结果

- 1B/30B tokens **超过** vanilla baseline 300B tokens → **10x 计算缩减**
- +5.3% avg accuracy over random (1B, 15 benchmarks)
- +2.2% over DCLM (最强 baseline) at 1B/30B
- 跨架构验证：Llama + Pythia, RefinedWeb + C4

### 对 QuaDMix 的启示

- **验证了轻量级 scorer 范式**：fastText 分类器可替代昂贵重训练
- **Predictive strength 可作为额外质量特征**加入 QuaDMix 的 5 个 FastText 分类器
- 但 PreSelect 是文档级选择，不涉及域级配比优化 — 与 QuaDMix 解决不同层次的问题

### 可信度评估

- **Venue**：**ICML 2025** — 顶级
- **机构**：HKUST (Junxian He) — 较强
- **代码**：开源 (github.com/hkust-nlp/PreSelect)
- **评级**：★★★★★ — ICML 2025 主会，开源，10x 计算缩减

## #32 GRASP: Geometry-aware Residual Alignment for Scalable Pretraining Data Attribution

**arXiv:2606.06892 | Wizard Quant+USTC | Yue Min, Ruining Chen, Yujun Li**

### 核心方法

**子集交互感知的数据归因**：
1. 将数据归因重构为子集级反事实效用预测
2. 线性相关性项（hidden-state + residual alignment）
3. **二次几何惩罚**：捕获数据冗余和互补
4. 低维特征 sketch（65 floats/example）实现可扩展性

### 关键结果

- Spearman rank correlation **翻倍**：ρ=0.361 vs 0.174 (TracIn)
- 构建成本：**0.27 天** vs 2.2 天 (TracIn/TRAK)
- 100K 子集扫描：**5.08 秒** (31x faster than TRAK)
- LM curation：最低 CC loss (2.9421)

### 对 QuaDMix 的启示

- **子集交互建模**是 QuaDMix 需要的能力：GRASP 的二次几何惩罚形式化了 QuaDMix 的 Q 矩阵近似
- **Sketch 效率**兼容 QuaDMix 规模（65 floats/example, 5s for 100K subsets）
- **关键发现**：additive scoring 在子集偏离参考语料时失效 — 这正是 QuaDMix 域重平衡的场景

### 可信度评估

- **机构**：Wizard Quant (unknown company) + USTC — 较弱
- **规模**：仅 50M 参数验证 — 小
- **Venue**：arXiv only
- **代码**：未公开
- **评级**：★★☆☆☆ — 方法有理论基础，但验证规模太小，机构不知名

## #33 DoGraph: Rethinking Data Mixing from the Perspective of Large Language Models

**arXiv:2604.07963 | HKUST-GZ+HIT+OpenCSG | Yuanjian Xu, Yang Liu, Guang Zhang**

### 核心方法

**从模型梯度视角重新定义"域"**：
1. Theorem 2.2：域差异编码在梯度几何中（MMD via gradient-induced kernel）
2. 每个 epoch：投影 per-sample 梯度 → random projection → K-means 聚类
3. 在 simplex 上求解最优域权重

### 关键结果

- GPT-2 Medium (SlimPajama)：最佳平均 **37.9%** vs 37.2% (DoReMi), 36.5% (DOGE)
- 最低验证 PPL：**3.09** vs 3.10 (Dynamic Loss), 3.30 (DoReMi)
- 推理 benchmark 提升最大：COPA +5.0, LogiQA +2.6

### 对 QuaDMix 的启示

- **关键发现**：人类定义的域与模型感知的域不一致 — QuaDMix 的 22 个 Dewey Decimal 域是否对 14M proxy 有意义？
- **梯度域重定义**可作为 QuaDMix 域分类的替代/补充
- 但 per-epoch 梯度计算开销远大于 QuaDMix 的离线 surrogate

### 可信度评估

- **机构**：HKUST-GZ + HIT + OpenCSG — 中等偏弱
- **规模**：仅 GPT-2 (210M-300M) + LLaMA-1.1B — 太小
- **Venue**：arXiv only
- **代码**：未公开
- **评级**：★★☆☆☆ — 理论洞察有价值（域误对齐），但实验规模太小不可靠

## #34 MIRA: Mid-training Rubric Anchoring for Source-Aware Data Selection

**arXiv:2605.30288 | 北航+上交+IQuest | Haowen Wang, Bryan Dai, Ming Zhou**

### 核心方法

**源感知的 mid-training 数据过滤**：
1. 按 embedding 相似度将 21 个源聚类为 5 组
2. Frontier teacher (Kimi-K2.6) 为每组提出质量维度
3. 聚类维度为 anchor rubrics
4. 蒸馏为组级 student scorers (Qwen3.5-35B-A3B-Base, ~3B active)
5. 源条件可靠性聚合 + 源级保留阈值

### 关键结果

- MIRA-Group macro avg **64.20** vs 63.23 (Random), 63.01 (DataMan)
- **用一半 tokens (25B) 匹配完整 50B corpus 性能**
- 21 sources, 5 source groups, 2M+ teacher-scored records
- Base model: Qwen2.5-Coder-14B

### 对 QuaDMix 的启示

- **源级质量 rubric** 与 QuaDMix 的 22 域结构平行 — 都认识到不同域需要不同质量标准
- **Student 蒸馏流水线**（frontier teacher → lightweight scorer）与 QuaDMix 的 proxy 方法类似但规模大得多（3B vs 14M）
- **源条件可靠性聚合**可启发 QuaDMix 的 quality-top-k：按域屏蔽不可靠的质量维度

### 可信度评估

- **机构**：北航 + 上交 + IQuest Research (Bryan Dai) — 中等
- **规模**：14B base model, 50B tokens — 较大
- **Venue**：arXiv only
- **代码**：未公开
- **评级**：★★★☆☆ — 方法完整，规模较大，但仅 code 领域验证

## 综合洞察

### 12. LR Schedule 与数据质量的协同设计

LR Decay paper (#28) 揭示了一个被忽视的问题：**数据选择策略和训练超参数必须协同设计**。QuaDMix 花大量精力优化数据配比，但如果 LR schedule 不匹配，质量信号会被浪费。这是所有 27 篇之前分析的论文都没有讨论的维度。

### 13. GP Surrogate 可能优于 LightGBM

MixAtlas (#29) 在相同预算下 GP 比 LightGBM (RegMix) 高 4-7 点，且提供不确定性量化。但 GP 的 O(n³) 扩展性和 QuaDMix 的 198 维搜索空间是瓶颈。建议：在低维子空间（如 5-10 个主域）上尝试 GP。

### 14. 网页图拓扑是正交的质量信号

WebGraphMix (#30) 证明了完全 training-free 的网页图中心度与 FastText 质量分数正交。1:1 中心/边缘混合 + 乘法组合可在 quality-top-k 基础上额外 +1.5%。实现成本仅 9 GPU-hours（一次性）。

### 15. 子集交互建模是下一步方向

GRASP (#32) 和 Domain-Aware SL (#27) 从不同角度指向同一问题：数据子集之间的交互效应。GRASP 的二次几何惩罚提供了一种形式化方法，但验证规模太小。结合 Domain-Aware SL 的 σ 值和 GRASP 的几何惩罚是潜在方向。

### 16. 人类定义的域 ≠ 模型感知的域

DoGraph (#33) 的理论发现值得重视：QuaDMix 的 22 个 Dewey Decimal 域可能与 14M proxy 的梯度感知不一致。建议：在 proxy 训练时记录 per-sample 梯度，用 PCA 或 random projection 检查域结构是否与梯度分布对齐。

### P0 — 立即行动

1. **修改 LR Schedule**（#28）：将 cosine decay 改为 moderate decay（最终 LR = peak 的 1/3）或 constant LR + checkpoint EMA 平均。预期收益：+1-3%，成本：改一行配置。

### P1 — 短期行动

2. **加入网页图中心度信号**（#30）：计算 Common Crawl host-level betweenness centrality，作为 FastText 质量分数的正交补充。乘法组合，50/50 混合。预期收益：+1.5%，成本：9 GPU-hours 一次性。

3. **检查域定义与 proxy 梯度的一致性**（#33）：在 proxy 训练中记录 per-domain 梯度分布，验证 22 个 Dewey Decimal 域是否与模型感知对齐。

### P2 — 中期探索

4. **GP Surrogate 替代 LightGBM**（#29）：在低维子空间（5-10 个主域）上尝试 GP + GP-UCB 主动采样，利用不确定性量化指导探索。

5. **Predictive Strength 质量特征**（#31）：将 PreSelect 的 predictive strength 作为 QuaDMix 的第 6 个质量特征加入 LightGBM。

6. **子集交互建模**（#32）：在 LightGBM 特征中加入 GRASP 风格的二次交互项，捕获域间冗余/互补。
