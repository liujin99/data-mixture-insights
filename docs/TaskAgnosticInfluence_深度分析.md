## 核心问题

现有数据影响力（data influence）方法都是 **task-specific** 的——衡量一条训练样本对某个下游任务/验证集的提升。这带来两个问题：
1. 结论依赖下游任务选择，换一个验证集结论可能不同
2. 预训练阶段没有明确的下游任务，无法在训练过程中评估数据贡献

**本文换了一个角度**：不关心"对哪个任务有用"，而是衡量"这条数据让模型参数向最终预训练参数靠近了多少"——task-agnostic。

## 核心方法

### 3.1 Mini-Batch 级影响力

定义当前参数到最终参数 θ* 的平方距离：

$$S_t = \|\theta^* - \theta_t\|_2^2$$

一个 mini-batch $B_t$ 的影响力 = 这次更新让距离**减少**了多少：

$$\text{Cont}(B_t) = S_t - S_{t+1} = 2\Delta_t^\top(\theta^* - \theta_t) - \|\Delta_t\|_2^2$$

- **第一项**：更新方向与"朝向最终参数方向"的对齐度（alignment）
- **第二项**：更新范数的惩罚项（penalty）

> 当更新方向与目标方向严重不一致时，Cont 可以为**负**——作者称为 **"opponent"（对手样本）**，即这次更新反而让模型远离最终状态。

### 3.2 样本级影响力

假设 SGD（简化分析，实际 Pythia 用 Adam），每个样本 $x_k$ 的更新为 $\Delta_{t,k} = -\eta_t \nabla_\theta \ell(x_k; \theta_t)$：

$$\text{Cont}(x_k^t) = 2\Delta_{t,k}^\top(\theta^* - \theta_t) - \Delta_{t,k}^\top \Delta_t$$

关键性质：**样本级影响力之和 = mini-batch 级影响力**。分解为：
- 样本自身范数项 $\|\Delta_{t,k}\|^2$
- 同 batch 内跨样本交互项 $\sum_{j \neq k} \Delta_{t,k}^\top \Delta_{t,j}$

**与 TracIn 的联系**：假设 batch 内各样本更新向量两两正交时，交互项消失，只剩范数项 = $\eta_t^2 \|\nabla \ell\|^2$，对应 TracIn 的 self-influence。噪声/错误标注样本梯度大 → 范数大 → 被惩罚 → 影响力低。

### 3.3 检查点近似（关键实用化步骤）

问题：精确计算需要每一步参数状态，但公开模型只给稀疏检查点。

解决：用相邻检查点 $c, c'$ 之间的参数差近似：
- $\theta_t \approx \theta_c$（用区间起点参数代替）
- $\Delta_t \approx \theta_{c'} - \theta_c$（用检查点间参数差代替 batch 更新）

$$\text{Cont}(x_k^t) \approx 2\Delta_{c,k}^\top(\theta^* - \theta_c) - \Delta_{c,k}^\top(\theta_{c'} - \theta_c)$$

**事后估算，无需重训**——这是方法能落地的前提。

## 实验设置

- **模型**: Pythia 全套（70M~12B，去重版）+ PolyPythia（160M/410M，多随机种子）
- **检查点**: 每个模型 154 个检查点（步 0,1,2,4,…,512,1000,2000,…,143000）
- **训练数据**: The Pile（300B tokens）
- **采样**: 每个检查点区间从**真实训练数据流**中采样 1,000 条样本算影响力
- **难度度量**: 用 Pythia-12B 最终检查点算 PPL（困惑度）
- **领域分类**: NeMo Curator Domain Classifier（26 个领域）

## 实验结果

### 4.2 贡献分布的演变轨迹

| 训练阶段 | 平均贡献 | opponent 比例 | 说明 |
|----------|----------|---------------|------|
| 早期 | 低 | 0~1% | 基础语言能力获取阶段 |
| 中期（~40k 步） | **峰值** | ~1% | 贡献最大，标准差也最大 |
| 后期 | 下降 | **8~10%** | opponent 显著上升 |

关键发现：
- 平均贡献在**中期**达峰，早期和晚期较低
- opponent 比例在 70k 步后明显上升，末期达 8~10%
- 这不单是学习率衰减导致——**对齐度也在下降**，晚期越来越多样本的更新方向与最终目标不一致

### 4.3 文本难度 vs 贡献

将样本按 PPL 分 5 个等量桶：

| 阶段 | 高 PPL 桶贡献占比 | 低 PPL 桶贡献占比 |
|------|-------------------|-------------------|
| 早期 | ~20% | ~20% |
| **中期** | **~25%**（↑5pp） | **~15%**（↓5pp） |
| 晚期 | ~20% | ~20% |

**高难度文本在中期贡献最大**，早晚期分布较均匀。

### 4.4 文本领域 vs 贡献

| 训练阶段 | 高贡献领域 | 低贡献领域 |
|----------|-----------|-----------|
| **早期** | 文学类（Books and Literature） | STEM 类（计算机/电子、科学） |
| **后期** | STEM 类 | 文学类 |

**核心发现：文学→STEM 交叉反转**。早期 STEM 文本（符号密集、结构复杂）贡献低，到后期反转为高贡献。论文附录 B.1 的定性示例显示：早期低贡献样本是"markup-heavy"技术内容、符号公式推导；早期高贡献样本是对话式自然语言。

|----------|------|------|

| 与 task-specific 对比 (5.4) | 与 TracIn-style（按域验证集）对比 | TracIn 结果**高度依赖**选哪个验证域，**不能**稳定复现文学→STEM 交叉现象 |

## 对预训练策略的启示（5.5）

1. **训练阶段划分**：与 PolyPythia 发现的"初始学习阶段(1k-10k)"和"关键学习阶段(10k-100k)"吻合——高 PPL 和 STEM 数据在关键阶段贡献最大
2. **不支持简单"由易到难"课程学习**：困难文本主要在中期贡献最大，而非线性地越到后期越重要
3. **支持分阶段数据配比**：近期 LLM 预训练在后期增加 STEM/数学/代码数据的做法，从轨迹层面获得实证支撑
4. **超越任务特定评估**：task-specific 归因对评估目标选择敏感，task-agnostic 方法能揭示阶段依赖的数据角色

## 局限性（论文自述）

- **参考依赖**：定义依赖特定预训练运行的最终参数，换个训练运行参考点就变
- **参数距离 ≠ 行为变化**：平方参数距离对参数化敏感，不直接反映模型行为变化
- **SGD 假设**：样本级分解假设 SGD，实际用 Adam（优化器状态未精确处理）
- **仅 Pythia 家族**：对其他架构/数据的普适性未知
- **观察性非因果**：characterize contribution 如何变化，未直接做数据配比干预实验验证因果效果
- **域效应与难度效应可能混淆**：高 PPL 和 STEM 领域高度相关，未完全解耦

## 深度批判：θ* 内生性与贡献度量的循环性

> 以下分析基于对该论文贡献度量逻辑的逐步审查，揭示了论文未讨论的根本性问题。

### 核心问题：θ* 是内生的

贡献度量的参考点是最终预训练参数 θ*。但 θ* 是**用被评估的同一批数据训出来的**。这意味着参考点不是独立的——它由被评估的数据本身决定。由此衍生三层循环论证：

### 第 1 层：梯度幅度混淆

贡献公式中，对齐项 $2\Delta^\top(\theta^* - \theta_t)$ 随梯度**线性**增长。高 PPL → loss 大 → 梯度大 → 对齐项机械增大 → 贡献偏高。

**部分反制**：惩罚项 $-\|\Delta\|^2$ 随梯度**平方**增长，对极大梯度有反制。所以不是单调的"梯度越大贡献越高"。但论文未做控制实验（控制梯度大小后看贡献差异是否消失），混淆未被排除。

### 第 2 层：θ* 自指性

$\theta^* - \theta_t = \sum_{\tau \geq t} \Delta_\tau$，即所有未来梯度之和。样本 $x_k$ 在第 $t$ 步的梯度方向天然和"未来要走的方向"相关——因为同域的其他样本在未来出现，把 θ 拉向该域。

**对个体样本偏弱**：The Pile ~200B tokens，每个序列基本出现 1~2 次，$x_k$ 自己在未来再现的概率极低。但对**域级**成立：域内大量样本共同把 θ* 拉向该域方向。第 2 层与第 3 层在域级合并。

### 第 3 层：域比例偏向

The Pile 固定比例（STEM ~15%、文学 ~5%，粗略）。数据多的域 → θ* 被拉向该域 → 该域样本梯度和 (θ* - θ_t) 天然对齐 → 贡献系统性偏高。

**对绝对贡献水平成立**：数据多的域贡献基线就高。但这不能单独解释文学→STEM 交叉反转——如果纯是比例效应，STEM（比例更高）应该**始终**贡献高于文学。交叉反转说明还有模型状态效应在起作用。

### 交叉反转 = loss 动态而非数据价值

**关键洞察**：交叉反转可以用一个更简洁的机制统一解释——**loss 下降速度差异驱动的梯度大小变化**。

| 阶段 | 文学 loss | STEM loss | 谁的梯度大 | 谁贡献高 |
|------|----------|----------|-----------|---------|
| 早期 | 高（刚学） | 高（更难学） | 相近，文学略高（更接近语言基底） | 文学 |
| 中期 | 已降（学会） | 仍高（未学会） | STEM >> 文学 | STEM（高 PPL 达峰） |
| 晚期 | 很低（熟练） | 仍高（很难学） | STEM >> 文学 | STEM + opponent 升 |

**一个机制解释全部发现**：
- 中期贡献达峰 ← 中期是 loss 分化最大的阶段（易的已降、难的未降）
- 高 PPL 中期贡献最高 ← 中期低 PPL loss 已降（梯度小），高 PPL 仍高（梯度大）
- 文学→STEM 交叉 ← 文学 loss 先降、STEM loss 后降 → 贡献先后交替
- 早期贡献均匀 ← 早期所有域 loss 都高 → 梯度差异小
- 晚期 opponent 升 ← 剩余极难样本梯度方向开始不一致

**结论**：交叉反转反映的是**学习动态**（先易后难），不是**数据价值排序**。论文声称"STEM 后期贡献高 → 支持后期增加 STEM 配比"，但这是循环的——STEM 后期贡献高只是因为 STEM 当前 loss 还没降，多加 STEM 当然降 loss，降完后贡献又会降，这是必然的。不能用它说"该加 STEM"，就像不能说"口渴时水贡献大所以该喝水"。

### 论文未控制的因素

| 需要控制的混淆 | 论文是否控制 |
|---------------|-------------|
| 高 PPL → 大梯度 → 高贡献（第 1 层） | ❌ 未做梯度大小控制实验 |
| θ* 由被评估数据训出（第 2/3 层） | ❌ 局限性提到"参考依赖"但未连接到 PPL 分析 |
| 域比例影响绝对贡献水平 | ❌ 未做域比例归一化 |
| loss 动态 vs 数据价值 | ❌ 未区分"loss 高导致贡献高"和"数据有价值导致贡献高" |

### 建设性结论：用 loss 而非贡献指导配比

批判的终点是一个**更有用的洞察**：

> **该在什么阶段加什么数据？看当前哪个域 loss 高（梯度大、未学会），就加那个域的数据。**

这比论文的"看贡献"更直接——贡献度量有循环性，但"当前 loss 高的域 = 未学会的域 = 该补的域"是**直接的、非循环的信号**。

这与本项目追踪的 **Velocitune (#61, ACL 2025)** 不谋而合：Velocitune 用学习速度 $V = (L_{current} - L_{target})/(L_{init} - L_{target})$ 动态调配比，学得慢的域（loss 还高）→ 增大权重，学得快的域（loss 已降）→ 减小权重。这正是用 loss 动态而非 θ* 贡献来指导配比。

**对比**：

| | 本文贡献度量 | Velocitune 学习速度 |
|--|------------|-------------------|
| 参考点 | θ*（内生，循环） | L_target（scaling law 预测，非循环） |
| 指导配比 | 间接（"贡献高"→"该加"？但循环） | 直接（loss 高 → 学得慢 → 该加） |
| 因果性 | 描述性（发生了什么） | 干预性（该做什么） |
| 需要重训？ | 否（事后分析） | 否（在线调整） |

## 与数据配比项目相关性

### 直接价值

1. **分阶段配比的轨迹层面旁证**：本文从数据贡献角度提供了"不同训练阶段数据作用不同"的实证。但注意（见深度批判）：贡献差异主要由 loss 动态驱动，而非独立的数据价值信号。与 Nemotron 3（两阶段 diversity→quality）、GLM-5（三阶段上下文递进）等头部厂商实践**方向一致但不构成因果证据**

2. **PPL 作为难度信号的启发**：论文用最终模型 PPL 分桶——但批判表明，PPL 高 → loss 大 → 梯度大 → 贡献高，这条链有机械混淆。PPL 作为**难度信号**仍有参考价值，但不应等同于"贡献大 = 该多用"

3. ~~文学→STEM 交叉反转：为后期增加 STEM 配比提供归因旁证~~ **修正**：交叉反转反映的是 loss 下降速度差异（先易后难），非数据价值排序。不能用它论证"后期该加 STEM"——那是循环论证。后期加 STEM 的依据应来自**目标能力需求**（你想提升 STEM → 该加），而非"STEM 贡献高"

4. **opponent 样本现象**：末期 8~10% 样本产生负贡献——但 opponent 也可能由循环性解释（梯度方向和 θ* 不对齐，而 θ* 本身是内生的）。opponent 现象的**非循环部分**仍有参考价值：末期数据质量筛选可能比增量更重要

5. **task-agnostic vs task-specific 的张力**：本文方法和 TracIn 给出不同结论——说明影响力度量本身有根本困境（task-agnostic 循环、task-specific 依赖任务选择）。配比决策应直接用 loss 动态信号（如 Velocitune）

### 对 QuaDMix 的启示

1. **分阶段动态配比**：QuaDMix 当前是静态最优解搜索，本文（和 RegMix-D #36、Velocitune #61 等）共同指向应该做 stage-aware 动态配比。但本文的"贡献"信号有循环性，**Velocitune 的学习速度信号更直接可用**
2. ~~PPL 分桶可作为质量信号补充~~ **修正**：PPL 与梯度大小强相关，作为"质量信号"有混淆。如要用 PPL，应与梯度大小解耦后使用
3. **opponent 概念可用于后期数据过滤**：但需注意 opponent 的循环性来源

### 不能直接照搬

- "贡献"≠ 下游能力提升，且贡献度量有循环性（θ* 内生）——不能把"高贡献"等同于"该多用"
- 交叉反转 ≠ 数据价值排序——只是 loss 动态的反映
- 结果仅来自 Pythia + The Pile，阶段转换时机和强度在其他架构/数据上可能不同
- 观察性分析非因果干预，需后续做配比干预实验验证
- **真正可直接用于配比决策的信号是 loss 动态（当前 loss 高 → 该补），而非贡献度量**
