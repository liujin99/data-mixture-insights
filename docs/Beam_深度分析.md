## 2. 数据管线与质量分档（§2.2）

**管线**（英文网页为例）：245B 原始页→精确去重（MD5）97B 文档→**域分区优先**（math/code/STEM/英文/非英，固定优先级级联 math→code→STEM）→模糊去重→启发式过滤→分类器过滤：**100.8T→6.69T，累计砍 93.4%**。

- **域分区保技术内容（量化账）**：MassiveWeb 标准阈值若施加于已策展技术数据，会砍掉 web-STEM/code/math 各 **80-88%**（合计 ~1.8T=混合唯一 token 的 13%）——"一尺寸过滤"对技术内容的代价首次被算成账。技术域必须先分区再各管各的
- **分类器（质量信号）**：in-house Keep-AUC **0.949** vs DCLM 0.595 / FineWeb-Edu 0.664；序数 Spearman 0.878 vs DCLM 0.017；**下游数据消融 1.35× compute efficiency vs DCLM**——分类器级三个便宜评测与下游消融排序一致（"廉价评测当代理"的受控验证）
- **质量分档加权（OLMo 3 式 20 个 token 加权质量档）**：保留 top-9 档（45% 网页 token）、截断指数递减、封顶 ~2×、均值 ~1.5×；**比均匀采样 +10% CE**
- **方法学金块两条**：
  - ① **因果消融**：同档位均匀采样对照组收益基本消失——起作用的是"识别质量+按档加权"整套机制，缺一不可（质量轴工业因果消融首例）
  - ② **最优保留比例随规模变宽**：最小尺度 top-3 最优→最大测试尺度 top-6→生产取 top-9（宁宽勿窄）——质量-数量权衡的规模依赖性，与 #01"门槛随模型变大而降低"同向
- **scaling ladder**：300M→23.4B 四个数量级、验证损失可预测、开源基座 Pareto 前沿；**DLS（data-limited subsampling）**：小档位按比例缩数据使各档轮次与生产 run 一致——**重复效应被纳入消融**（连"多 epoch"轴：多数 TR 的 ladder 消融隐含全新数据，Beam 显式纠正这一点）

## 3. MT 两阶段（§3）——**库内第二家 MT 回放数字披露**

- **Stage 1**（850B @ 32K，69h，goodput 81.3%）：**90% 新数据+10% 高质量 PT 数据保召回**（防遗忘+防过拟合正则）；按目标 token 份额=**45% code**（竞编/基础 SWE/终端）**+30% 中高阶 STEM+15% 通用知识**
- **Stage 2**（100B @ 512K，24.8h，goodput 86.1%）：**50% 有机长上下文**（书/论文/按跨文件依赖打包的 repo）**+15% 合成长上下文 QA/IF+35% 召回数据（PT+Stage1）**——权重经网格搜索定（长上下文涨 vs 其他能力退的权衡）
- **回放读法（库内连线，本篇对库最大价值）**：
  - NVIDIA 20%+消融（40% 无增益）之后**第二家工业 MT 回放披露**：Beam Stage1 **10%**/Stage2 **35%**——**剂量随阶段/目的变**（Stage2 扩上下文需更多锚定），甜点区比"20% 一个点"宽得多（10-35% 全在用）
  - 与 Marin SFT 实验（5-20% 不可分、单旋钮效应≈种子噪声地板）拼起来：**回放剂量在甜点区内不敏感、过 40% 才明确坏**——"业界定个 20% 不精调"解释链的第三块拼图
  - Stage1 域数据 45+30=**75%**——与 3.5/Singhal"域数据 ~75%"**同值**（第三家收敛）
- **训练设置**：MT LR=**PT 峰值的 5%**（7.64e-4×5%≈3.8e-5——与 GLM-5 MT 起点 4e-5 同值级；NVIDIA 重置恒定：三家三种做法、量级同域）；每阶段重置优化器状态+预热；**关掉 MoE 专家均衡损失**（z-loss/序列辅助损失/专家偏置全禁——MT 分布偏技术域，强均衡阻碍专家特化）
- **MT 数据消融协议**：每次 50% 上一轮稳定混合+50% 待测新源——单源隔离+数据-能力交互早发现；训练确定性+loss/梯度尖峰反查坏数据，定制过滤器固化
- **数据哲学（correctness-anchored）**：licensed 种子→变换管线（任务合成/轨迹生成改写/教学内容）；**多开源模型分饰角色**（策展/改写/解题出真值/验证质量/过滤）"无单一模型怪癖主导"；难度 pass@k 校准至当前 checkpoint 能力前沿（太难=查题面歧义/有损改写）——为 RL 铺"可验证"地基

## 4. RL 任务池与奖励完整性（§4.1）

- 池子：数百万可验证任务（开源仓库+采购+自建管线合成）→**aggressive 过滤至 ~100 万**最难最高质量
- **质量=奖励零噪声**：任务不误导（题面完整、前提成立）、不可钻（奖励只在真解时给）、验证器稳定一致（同答同分）；**专门造"对抗性智能体"主动攻击验证器**，能钻到 1.0 奖励的任务一律剔除
- **难度按当前模型校准**：组内全 0/全 1 均弃；且防"错因"（答案漏在题里=假易；上下文不足=假难；模板格式错误掩盖真难度；不可能题诱发 hacking）
- **来源排序**：**in-house 管线>开源环境（须重度质量+难度过滤才可用）>vendor（贵）**——"现成开源 RL 环境撑不起大规模 RL"的工业证词
- **奖励完整性设计**：判作弊→正确性得分归零**但长度代价照算**（作弊不比同长失败便宜）——大规模 RL 不崩的隐形护栏
- 去污双阈值：训练样本间 Jaccard 0.95、涉评测样本 0.80
- effort=显式输入+线性长度惩罚（超预算终止且无正确性奖励）——RL 同时教会"按预算思考"；held-out 八基准全程一致设置反复评测，曲线无平台期
- **跨域迁移**：83% 进度前无搜索/浏览任务，BrowseComp 却 50.1→57.9 一路涨；纯 STEM 阶段 SWE 不掉、纯 SWE 阶段 STEM 不退——RL 学的是可迁移的分解+用工具（#161"MT 引出论"的 RL 侧平行）

## 5. MOPD 双教师融合（§4.3）——**MOPD 第二家工业实现**

- agentic expert（短 SFT 定格式+RL）与 alignment teacher（安全/校准/对话）分开训练→**MOPD 蒸馏进单学生**；全词表 reverse KL @ 学生访问的上下文（现行学生概率对词表直微——无 sampled-token 修正）；**概率路由** r(x)~Bernoulli 按任务族选教师（双语域 50/50 混合）
- 工程优化：传教师 **hidden states** 在 trainer 重构 logits（O(N·d) vs O(N·V)——DeepSeek-V4 同法）
- **split-braining（自命名失败模式）**：担心合并学生只按提示分布"切换老师"而非真融合——检验=混合任务（对话式提示嵌高难推理题）：无显著退化，通过；附带发现：agentic 分布特征"刻得深"（弱线索唤不回对齐行为）
- **replicator 方程**：单 run 拟合学习常数→从 SFT checkpoint 预测各组件 RL 增益，**318 个后训练 run** 验证预测与实测吻合；同一方程预测奖励函数改动对不良行为的压制——**"后训练可预测性"工具**（连 #172：OpenAI 损失层预测能力涌现，Beam=RL 动力学层预测训练收益——可预测性主张的两支）
- **对齐教师 100B→501B**（训练设置不变）：**误拒率相对降 48.7%**、有害通过率仅 +3.1%——"模型容量本身是安全解法一部分"的量化首例

## 6. 噪声与验证纪律（连手册"验证信号纪律"行）

- **CE（compute efficiency）变化 >5% 才算真信号**（抵消训练种子噪声+采样噪声）——工业噪声地板的又一家定量表述（与 Marin"单旋钮效应≈种子噪声地板"同族独立收敛）
- "every pretraining recipe intervention must be ablated on the scaling ladder"——**手调+消融再+1**（无自动搜索定生产配比；质量档位/超参/LR-WD 缩放律全在小档手扫拟合再外推）
- RL"无平台期"结论限定于自家套件+一致设置（temp 1/top-p 0.99/effort 512）——论文与解读文均自列此 caveat

## 7. 工程透明（§6，配比域外但系"透明度"标尺事件）
