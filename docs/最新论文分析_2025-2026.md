## 第一梯队：大厂 + Top Venue，高可信度

### 1. CAMEL: Capacity-Aware Mixture Law Enables Efficient LLM Data Optimization ⭐⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | 清华 IIIS (Jingzhao Zhang, Xinran Gu — Phase Transitions 同一团队) |
| **arXiv** | 2603.08022 (Mar 2026) |
| **PDF** | `09_CAMEL_Capacity_Aware_Mixture_Law_Tsinghua.pdf` |
| **可信度** | 高 (Phase Transitions 团队 follow-up) |

**核心贡献**：
- 在 Phase Transitions 的容量分配理论基础上，提出 **capacity-aware mixture law**
- 引入 **loss-to-benchmark 预测**，直接从 loss 预测下游 benchmark
- 在 MoE 模型 (7B-A150M) 上拟合，外推到 55B-A1.2B
- 减少 **50% 优化成本**，benchmark 提升 **3%**

**对 QuaDMix 的价值**：**极高**
- 这是 Phase Transitions 论文的**实践版**
- 之前你说 Phase Transitions 不能给明确方向 — CAMEL 就是他们给出的方向
- 把理论转化成了可操作的优化方法

**关键洞察**：
- Phase Transitions 告诉我们"小 proxy 信号不可靠"
- CAMEL 告诉我们"如何用 capacity-aware 的方法修正这个不可靠性"

### 2. Can Small Training Runs Reliably Guide Data Curation? ⭐⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Princeton + UC Berkeley + Stanford** |
| **作者** | Jiachen T. Wang, Kaifeng Lyu (Phase Transitions 同一人), James Zou, Dawn Song, Prateek Mittal |
| **Venue** | **ICLR 2026** (accepted) |
| **arXiv** | 2512.24503 |
| **PDF** | `10_Proxy_Reliability_Small_Training_Runs_ICLR26.pdf` |
| **可信度** | 极高 (顶会 + 强作者团队) |

**核心发现**：
- 标准 proxy 实验用**相同超参数**训练所有配比，会导致**结论翻转**
- 提出简单修复：**降低 proxy 的 learning rate**，就能让 proxy 结果与大模型全调参结果强相关
- 在 **23 个数据配比**上验证

**对 QuaDMix 的价值**：**极高**
- QuaDMix 的 1M proxy 如果用了不合适的 LR，整个搜索可能无效
- 这篇论文给出了**具体的修复方案**
- 直接相关，可立即实施

**关键洞察**：
- Proxy 实验的超参数设置比想象中更重要
- 降低 LR 是一个简单但有效的 patch

### 3. DataMan: Data Manager for Pre-training LLMs ⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Alibaba Qwen 团队** (Junyang Lin, Dayiheng Liu) |
| **Venue** | **ICLR 2025** |
| **arXiv** | 2502.19363 |
| **引用** | 12 |
| **PDF** | `11_DataMan_Alibaba_Qwen_ICLR25.pdf` |
| **可信度** | 高 (大厂 + 顶会 + 高引用) |

**核心贡献**：
- 从 perplexity 异常原因和 15 个应用领域推导出 **14 条质量标准**
- 训练 Data Manager 标注 **447B token** 语料
- 选 30B tokens 用 DataMan 筛选，优于 **1.5x 数据量**的 uniform 采样

**对 QuaDMix 的价值**：高
- Qwen 团队（真正训过 70B+ 模型的人）的质量标准体系
- 可以直接作为 QuaDMix Eq.1 质量信号的参考
- 14 条质量标准可作为 quality merger 的输入特征

**关键洞察**：
- 大厂的质量标准是经过大规模实验验证的
- 14 条标准覆盖了 perplexity 异常的主要原因

### 4. Optimizing Pretraining Data Mixtures with LLM-Estimated Utility (UtiliMax / MEDU) ⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Meta FAIR** |
| **作者** | William Held, Bhargavi Paranjape, Mike Lewis, Todor Mihaylov 等 |
| **arXiv** | 2501.11747 (Jan 2025) |
| **PDF** | `12_Meta_UtiliMax_LLM_Estimated_Utility.pdf` |
| **可信度** | 高 (Meta FAIR) |

**核心发现**：
- 简单的 **token-count 启发式方法**（按 domain 的 token 数量反比加权）竟然**优于**人工调参和 learned mix
- 提出 **UtiliMax**（消融法估计 domain 效用）和 **MEDU**（用 LLM 从小样本估计效用）
- 实现 **~200x 计算缩减**

**对 QuaDMix 的价值**：高
- Meta 的经验表明 token-count heuristic 是个 strong baseline
- QuaDMix 应该先和这个 baseline 对比
- MEDU 方法可能比 proxy 训练更便宜

**关键洞察**：
- 有时候简单方法（token-count）比复杂方法更有效
- LLM 估计效用是一个值得探索的方向

### 5. Scaling Laws for Mixture Pretraining Under Data Constraints (Repetition-aware) ⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Apple** (Pierre Ablin 组，与之前分析的 Scaling Laws 同一团队) |
| **作者** | Anastasiia Sedova, Pierre Ablin 等 |
| **arXiv** | 2605.12715 (May 2026) |
| **PDF** | `13_Apple_Repetition_Aware_Mixture_Scaling.pdf` |
| **可信度** | 高 (Apple, 同一团队第三篇) |

**核心发现**：
- 基于 **2000+ 训练 runs**
- 发现稀缺目标语料在混合训练中可重复使用 **15-20 次**（远多于单源训练）
- 为数据受限场景（多语言、领域特定、质量过滤后）提供配比建议

**对 QuaDMix 的价值**：高
- QuaDMix 的高质量数据通常量小
- 这篇直接回答了"高质量数据该重复多少次"
- 15-20x 重复是一个具体的数字指导

**关键洞察**：
- 混合训练中的数据重复容忍度比单源训练高得多
- 这可能是因为其他 domain 的数据提供了"正则化"

### 6. Demystifying Synthetic Data in LLM Pre-training ⭐⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Meta** (Carole-Jean Wu 组) |
| **Venue** | **EMNLP 2025 Main Conference** |
| **arXiv** | 2510.01631 |
| **PDF** | `14_Meta_Synthetic_Data_Pretraining_EMNLP25.pdf` |
| **可信度** | 高 (Meta + 顶会) |

**核心发现**：
- **>1000 个 LLM 训练实验**，**>100k GPU hours**
- **1/3 改写合成数据 + 2/3 自然数据**可加速训练 **5-10x**
- 好的合成数据比例收敛到 **~30%**，与模型大小无关
- 更大的生成模型不一定产出更好的数据

**对 QuaDMix 的价值**：中
- 如果 QuaDMix 的数据池包含合成数据，这篇给出了明确的配比指导
- 30% 合成 + 70% 自然是一个具体的起点

**关键洞察**：
- 合成数据的最佳比例是 ~30%，这个数字很稳定
- 不需要用 70B+ 模型生成合成数据，8B 就够了

### 7. OP-Mix: Always Learning, Always Mixing ⭐

| 项目 | 内容 |
|------|------|
| **机构** | **NYU + Google DeepMind** (Kyunghyun Cho, Tal Linzen) |
| **arXiv** | 2605.15220 (May 2026) |
| **PDF** | `15_OPMix_NYU_DeepMind.pdf` |
| **可信度** | 高 (DeepMind + 知名作者) |

**核心贡献**：
- 把数据配比当作整个训练生命周期的**在线决策问题**
- 用 **low-rank adapter 插值**来廉价模拟候选配比
- 预训练 perplexity 提升 **6.3%**
- continual learning 用 **66% 更少计算**达到同样效果

**对 QuaDMix 的价值**：中
- LoRA 插值作为 proxy 的思路 — 比训完整模型便宜，比 model merging 灵活
- 但需要评估是否适用于 QuaDMix 的场景

**关键洞察**：
- 动态调整配比（而非固定配比）可能更好
- LoRA 插值是一个值得探索的 proxy 方法

### 8. Demystifying Data Organization for Enhanced LLM Training ⭐

| 项目 | 内容 |
|------|------|
| **机构** | **Microsoft Research** |
| **Venue** | **ACL 2026 Main Conference** |
| **arXiv** | 2605.30334 |
| **PDF** | `16_Microsoft_Data_Organization_ACL26.pdf` |
| **可信度** | 高 (Microsoft + 顶会) |

**核心发现**：
- 数据顺序（不只是配比）对训练效果有显著影响
- 提出 4 条准则：
  1. **Boundary Sharpening** — 清晰的数据切换边界
  2. **Cyclic Scheduling** — 周期性重复数据
  3. **Curriculum Continuity** — 平滑的课程学习过渡
  4. **Local Diversity** — 局部保持多样性

**对 QuaDMix 的价值**：中
- QuaDMix 目前只优化配比，不优化数据顺序
- 这篇说明顺序也是重要变量
- 可以作为 QuaDMix 的扩展方向

**关键洞察**：
- 数据配比和数据顺序是两个独立的优化维度
- 顺序优化的成本可能比配比优化低

   - 如果数据池包含合成数据，使用 30% 配比
   - 不需要用大模型生成

## 关键洞察总结

### 1. Proxy 可靠性是核心问题

三篇论文从不同角度指向同一个问题：
- **Phase Transitions** (NeurIPS'25): 小 proxy 信号可能完全无效（理论）
- **Proxy 可靠性** (ICLR'26): 超参数设置会导致结论翻转（实证）
- **CAMEL** (2026.3): 用 capacity-aware 方法修正不可靠性（方法）

**结论**：QuaDMix 的 1M proxy 是最大的风险点，需要立即修复。

### 2. 简单方法可能是最好的

- **Token-count heuristic** (Meta UtiliMax): 优于人工调参和 learned mix
- **降低 LR** (Proxy 可靠性): 简单 patch 解决大问题
- **15-20x 重复** (Apple): 比想象中高得多

**结论**：不要过度工程化，先试试简单方法。

### 3. 大厂经验值得参考

- **DataMan** (阿里 Qwen): 14 条质量标准，447B token 标注
- **Meta 合成数据**: 30% 配比，5-10x 加速
- **Apple Repetition-aware**: 2000+ runs 的经验

**结论**：这些是真正训过 70B+ 模型的人的经验，值得参考。
