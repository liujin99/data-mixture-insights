## 核心问题

### 个体选择 vs 组级选择的根本差距

现有数据选择方法（MATES, DSIR, QuRating 等）都是**逐条打分**：给每个样本一个分数，选分数最高的 n 个。

隐含假设：**组的价值 = 个体价值之和**。

但这篇论文用实验证明这个假设**严重不成立**：

1. **选择集快速分裂**：个体选择 vs 贪心组级选择，在选 100 个样本时重叠率就降到接近随机（<50%）
2. **性能差距翻倍**：组级选择的性能增益（vs random）是个体选择的 **2 倍**

### 为什么个体之和 ≠ 组级价值？

数据点之间有**交互效应**：
- **抵消效应**（Cancellation）：两个高质量但内容重叠的样本，一起用时价值 < 各自价值之和
- **放大效应**（Amplification）：两个单独看一般的样本，互补性强，一起用时价值 > 各自价值之和

这跟 QuaDMix 的核心关切高度一致——**配比不是简单的样本质量加权**。

## 方法：Group-MATES

### 核心思想

用一个**关系数据影响模型**（Relational Data Influence Model）来近似昂贵的组级选择：

```
Θ^rel(x_t | D_{t-1}) = [α - α/(β·(t-1)) · Σ R_{x_i, x_t}] · (w_o · h_{x_t})
                        ↑ 关系修正项（考虑已选数据）    ↑ 个体影响预测
```

其中：
- `w_o · h_{x_t}`：个体数据影响（同 MATES）
- `R_{x_i, x_t} = cos(h_{x_i}, h_{x_t})`：关系权重（embedding 余弦相似度）
- `α, β`：可学习缩放因子

**直觉**：如果候选样本 x_t 跟已选样本高度相似（R 大），则降低其影响分数（避免冗余）；如果跟已选样本互补（R 小或负），则保持或提升分数。

### 训练流程

**Step 1: 采样训练轨迹**
- 从预训练中间 checkpoint 出发
- 用随机策略 π_rand 采样 20,000 条训练轨迹（每条长度 T=10）
- 每步收集 oracle 数据影响（单步梯度更新后的参考 loss 变化）

**Step 2: 训练初始模型**
- 用随机轨迹数据训练初始关系影响模型 Θ_init^rel

**Step 3: Bootstrapping**
- 用 Θ_init^rel 采样新轨迹（选预测影响最高/最低的样本）
- 合并两批数据训练最终模型 Θ_final^rel
- Bootstrapping 提升 Spearman 相关上界 **+0.18**

### 推理：基于聚类的加速

直接对全数据集做组级选择复杂度 O(N·n)，不可行。

**解决方案**：
1. 用关系权重 R 做 k-means 聚类（d=10,000 个 cluster）
2. 每个 cluster 内独立做组级选择
3. 预算按 cluster 大小比例分配

**加速效果**：>10^6 倍

### 模型架构

- **Backbone**: bge-base-en-v1.5（sentence embedding 模型）
- **Embedding**: [CLS] token 的 last hidden state, R^768
- **长序列处理**: 2048 tokens 切成 4 个 512 chunk，分别过 BGE，取平均
- **训练成本**: 仅 **2.7 H100 小时**（与目标模型规模无关）

## 实验结果

### 主实验（DCLM benchmark, 22 个下游任务）

| 方法 | 400M-4x Core | 1B-1x Core | 3B-1x Core |
|------|-------------|-----------|-----------|
| Random | 0.21356 | 0.29456 | 0.35603 |
| Edu Classifier* | 0.21821 | 0.29257 | - |
| WebOrganizer* | - | 0.29488 | - |
| MATES | 0.22260 | 0.30288 | 0.36139 |
| Quad | 0.22358 | 0.29340 | - |
| **Group-MATES** | **0.23362** | **0.30747** | **0.36846** |

**关键数字**：
- vs Random: **+3.5% ~ +9.4%** 相对提升
- vs MATES: 在 400M 和 3B 上**翻倍**其 vs random 的增益
- 3B 上 MATES 增益衰减，Group-MATES 保持稳定

### Speed-Quality Frontier

- 达到同等性能，token 需求减少 **最高 1.75x**
- FLOPs 减少 **最高 1.3x**（含选择开销）

### 消融实验

| 消融项 | Core (400M-4x) | vs Full 下降 |
|--------|---------------|-------------|
| Full Group-MATES | 0.23362 | - |
| w/o Relationship term | 0.22737 | **-31%** 增益 |
| w/o Bootstrapping | 0.22924 | -22% 增益 |
| w/ Semantic clustering | 0.23042 | -16% 增益 |

**结论**：关系权重是最关键组件。

### 选择开销（FLOPs 占比）

| 规模 | 预训练 | 选择总开销 | 占比 |
|------|--------|-----------|------|
| 400M-4x | 87.8% | 12.2% | 较高 |
| 1B-1x | 93.3% | 6.7% | 可接受 |
| 3B-1x | 96.6% | 3.4% | 很小 |

**随模型规模增大，选择开销占比递减**。

### vs 领域配比方法

1B-1x 上：
- WebOrganizer（领域构建 + RegMix 配比优化）: Core = 0.29488（仅比 random +0.1%）
- Group-MATES: Core = 0.30747（比 random +4.4%）

**组级样本选择大幅优于领域级配比优化**。

## 对 QuaDMix 的启示

### 高相关性

1. **核心问题一致**：都在解决"数据组合效应"问题
   - QuaDMix 的 quadratic mixing 本质上也是在建模数据间的交互
   - Group-MATES 用关系权重 R 来建模，QuaDMix 用二次型 w^T Q w

2. **验证了 QuaDMix 的方向正确**：
   - 个体选择 vs 组级选择的差距是真实的（实验证明翻倍）
   - 这支持 QuaDMix 超越简单加权求和的动机

3. **关系权重思路可借鉴**：
   - 用 embedding 余弦相似度作为交互项的权重
   - 这比 QuaDMix 当前的二次型更轻量、更有理论支撑

### 中等相关性

4. **聚类加速策略**：
   - 10,000 clusters + cluster 内独立选择
   - 如果 QuaDMix 的二次优化在大域数下太慢，可以考虑类似分解

5. **Bootstrapping 训练策略**：
   - 先随机采样训练初始模型，再用初始模型指导采样训练最终模型
   - QuaDMix 的 proxy 训练也可以考虑类似策略

### 低相关性 / 局限性

6. **规模验证不足**：最大只测到 2.8B，未验证 7B+
7. **不是配比方法**：Group-MATES 是样本选择（从 N 个里选 n 个），不是领域配比（给 K 个领域分配权重）
8. **一次性选择**：选完就训，不像 QuaDMix 可以动态调整配比
9. **DCLM 特定**：数据已经过高质量清洗，在噪声更大的数据上效果未知

## 总结

Group-MATES 最重要的贡献是**用实验量化了"组级效应"的大小**：

- 个体选择 vs 组级选择性能差距 **2x**
- 这直接回答了"为什么不能简单加总个体分数"

对 QuaDMix 而言，这篇论文：
1. **验证了方向**：数据交互效应是真实且显著的
2. **提供了工具**：关系权重（embedding cosine similarity）是一个轻量且有效的交互建模方式
3. **暴露了差距**：QuaDMix 的二次型 Q 矩阵是否比简单的 cosine similarity 更好？值得实验对比
