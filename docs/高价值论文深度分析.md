## TOP 1: DeMix — Model Merging 替代 Proxy 训练

| 项目 | 内容 |
|------|------|
| **发表** | ICML 2026 (accepted) |
| **机构** | 小红书 + 东京大学 + 清华 |
| **arXiv** | [2602.00747](https://arxiv.org/abs/2602.00747) |
| **PDF** | `04_DeMix_Model_Merging_ICML26.pdf` |
| **开源** | [github.com/Lucius-lsr/DeMix](https://github.com/Lucius-lsr/DeMix) + 22T token 数据集 |

### 业界关注度: 极高

这是当前数据配比领域**最热的技术路线转变**。

### 核心对比

| 传统方法 (QuaDMix/RegMix/CLIMB) | DeMix |
|---|---|
| 每个配比采样 → 训练一个 proxy model → 评估 | 训练 N 个 domain expert → 加权合并 = 任意配比 proxy |
| 搜索成本 ∝ proxy数量 × 单个训练成本 | 搜索成本 ≈ 0（合并后直接推理） |
| 112 个 proxy 需要 224-1344B tokens | 7 个 component model × 30B = 211B tokens，可生成**无限** proxy |

### 关键技术细节

1. **小更新假设**: 参数更新幅度 δ ≈ 10%，满足 Δ(Di ∪ Dj) ≈ Δ(Di) + Δ(Dj)，因此加权合并 ≈ 联合训练

2. **Linear merging 最优**: 对比了 Multi-SLERP、DARE、TIES、DELLA、Breadcrumbs 六种合并策略，**最简单的加权线性合并效果最好**
   - Capability Recovery: 0.845
   - Spearman ρ: 0.787

3. **必须混入 50% 通用数据**: component model 训练时通用数据比例从 50% 降到 0%，ρ 从 0.787 暴跌到 0.652

4. **迭代搜索流程**:
   - 3 轮采样: 64 → 32 → 16 个配比
   - 每轮: 合并 → 评估 → LightGBM 回归 → 重采样
   - 最终取 top-128 平均作为最优配比

5. **大规模验证**: 在 Qwen3-1.7B 和 Qwen3-8B 上均有效，15 类细粒度数据划分也有效

### 实验数据

**Proxy 一致性 (Table 2)**:
- DeMix (30B component): macro avg ρ = 0.81, top-25% ρ = 0.59, 总成本 211B tokens
- Trained Proxy (12B per proxy × 112): macro avg ρ = 0.54, top-25% ρ = 0.20, 总成本 1344B tokens
- **成本节省 6.4x，精度提升 50%+**

**最终配比质量 (Table 3)**:
- DeMix 224 proxies: avg rank 24.00
- RegMix 56×8B: avg rank 27.67
- CLIMB 56×8B: avg rank 29.00

### 对 QuaDMix 的价值

- **直接竞争关系**: DeMix 的 proxy 生成方式从根本上替代了 QuaDMix 的"每个配比训练 1M proxy"
- **成本对比**: QuaDMix 200 个实验 × proxy 训练 vs DeMix 7 个 component model + 无限推理
- **可融合点**: QuaDMix 的 Eq.1-3 质量-多样性采样 + DeMix 的 model merging proxy = 潜在最优方案
- **开源了 22T token 数据集 + 代码**，可直接复用

## TOP 2: Apple Scaling Laws for Optimal Data Mixtures

| 项目 | 内容 |
|------|------|
| **机构** | Apple (Pierre Ablin 组) |
| **arXiv** | [2507.09404](https://arxiv.org/abs/2507.09404) |
| **PDF** | `03_Scaling_Laws_Optimal_Data_Mixtures_Apple.pdf` |

### 业界关注度: 高

这是目前**最严谨、最通用**的数据配比 scaling law 框架。

### 核心技术

#### 两种 Scaling Law 形式

**Additive Law** (5+2k 参数):
```
L(N, D, h) = E + 1/Σ(Ci·hi^γi) + A/N^α + B/D^β
```
- 最优配比 h* **与模型大小 N 和 token 数 D 无关**
- 一次拟合，永久使用

**Joint Law** (5+4k 参数):
```
L(N, D, h) = E + 1/Σ(Ci·hi^γi) + Ah/N^α + Bh/D^β
where Ah = (Σ CAi·hi)^γA, Bh = (Σ CBi·hi)^γB
```
- 最优配比 h* **随计算预算 (N,D) 变化**
- 更精确但需要更多数据

#### 拟合成本极低

| Domain 数量 | 所需训练 run 数 |
|:---:|:---:|
| 3-4 | **10 组** |
| 6-8 | **20 组** |

用小模型（100M-1.4B）拟合，外推到大模型（7B-8B）。

#### 跨模态验证（独一无二）

| 模态 | 模型规模 | Token 数 | Domain 数 | MRE |
|------|---------|---------|----------|-----|
| LLM | 7B | 150B | 7 (SlimPajama) | 0.1-4.5% |
| NMM | 8B | 160B | 3 (text+image+interleaved) | 0.1-6.2% |
| LVM | 1B | 330B | 4 (image qualities) | 0.3-2.0% |

#### 关键发现: OpenHermes 作为 Target Domain

拟合 OpenHermes 的 scaling law 并优化配比 → 7B 模型全面优于 baseline:

| 指标 | h*_OH (优化) | Uniform | Base SlimPajama |
|------|:---:|:---:|:---:|
| MMLU | **37** | 30 | 25 |
| BoolQ | **67** | 46 | 51 |
| PIQA | **79** | 78 | 79 |
| CORE | **58** | 53 | 52 |

**这与 QuaDMix 用 OpenHermes 做验证集的思路完全一致。**

#### 拟合方法

- **Basin-hopping + L-BFGS**: 比纯随机搜索 L-BFGS 初始化收敛快 10x+
- **Huber loss** (δ=1e-3): 对异常值更鲁棒
- **Mirror descent**: 在 simplex 上优化 h*

### 对 QuaDMix 的价值

- **可直接替代 LightGBM**: 用参数化 scaling law 替代黑盒回归，可解释性大幅提升
- **Additive law 的独立性**: 一旦拟合，最优配比不随 (N,D) 变化 → 一次拟合，永久使用
- **Joint law 的 scale-dependent 优化**: 如果 QuaDMix 需要针对不同目标模型大小给出不同配比
- **10-20 组 run 即可**: 比 QuaDMix 当前 200 个实验少一个数量级
- **OpenHermes 验证**: 证明 QuaDMix 选择 OpenHermes 作为验证集的方向正确

## TOP 3: Phase Transitions in Data Mixing (NeurIPS'25 Spotlight)

| 项目 | 内容 |
|------|------|
| **机构** | 清华大学 (Jingzhao Zhang 组) |
| **发表** | NeurIPS 2025 Spotlight |
| **arXiv** | [2505.18091](https://arxiv.org/abs/2505.18091) |
| **PDF** | `01_Phase_Transitions_Data_Mixing_NeurIPS25.pdf` |

### 业界关注度: 高（理论突破性最强）

这篇论文揭示了数据配比中一个**根本性的理论困难**，对所有 proxy-based 方法构成威胁。

### 核心发现

#### 相变现象

**模型大小相变** (Figure 1):
- 固定配比 r，增大模型大小
- 准确率从 0% 突然跳到 60%+
- 临界模型大小 M_thres 随 r 减小而增大

**配比相变** (Figure 2):
- 固定模型大小，增大配比 r
- 准确率从 0% 突然跳到 80%+
- **低于临界配比时，即使训练 256B tokens（每个传记出现 3000 次），模型仍然什么都学不到**

**训练时长无效** (Figure 3):
- 所需训练步数 T 与 1/r 的关系：初始线性增长，很快变为**指数甚至超指数增长**
- r=0.25 时实际 T 是 power-law 预测的 2.9x
- r=0.2 时实际 T 是 power-law 预测的 1.9x

#### 信息论解释（严格证明）

模型是有限容量的"背包问题求解器"，按"边际价值"分配容量:

```
边际价值 = 分配额外一单位容量到某数据集带来的 test loss 下降
```

- 知识密集数据的边际价值在低配比时可能为零 → 不分配任何容量
- 只有当 r 或 M 超过阈值时，知识密集数据才"值得学习"

**临界配比的 Power-law**:
```
r_thres ~ 1/M^(α+1)
```
其中 α 是 web 数据 loss 关于模型大小的 scaling exponent。

#### 实验验证

| 实验 | 数据 | 模型 | 结果 |
|------|------|------|------|
| 合成传记 | SynBio + FineWeb-Edu | Pythia 14M-6.9B | 相变存在 |
| 推理任务 | OpenWebMath (slope) + FineWeb-Edu | Pythia 70M-410M | 相变存在 |
| 真实知识 | PopQA + Wikipedia | Llama-2, Qwen-2.5, Gemma-2 | 阈值频率遵循 power-law |

**Power-law 验证** (Figure 7):
- SynBio 实验: 拟合斜率 -1.152，理论预测 -1.283 (α=0.283)
- PopQA: Llama-2/Qwen-2.5/Gemma-2 均呈现线性关系

#### 实用策略

**Random Subsampling**: 随机子采样知识数据
- WikiBio 上学习到的事实数提升 **4x**

**Compact Knowledge Mixing (CKM)**: 将知识改写为紧凑形式
- WikiBio 上学习到的事实数提升 **20x**
- 核心思想: 提高每条事实的暴露频率 → 提高边际价值

### 对 QuaDMix 的价值

- **这是 QuaDMix 最大的理论风险**: 1M proxy model 和 target model（可能 7B+）处于不同相的概率很高
- **Power-law 公式可用于检测**: r_thres ~ 1/M^(α+1)，可以估算 proxy 和 target 是否跨越相变边界
- **CKM 策略可直接实现**: 在 QuaDMix 的 Eq.3 sigmoid 采样前，对高质量数据做紧凑改写
- **论文 Takeaway 2 直接点名**: "Naively measuring the performance of small models on a small data domain may provide little to no predictive signal on how well larger models perform" — 这是对 QuaDMix proxy 路线的直接警告

## 对 QuaDMix 的具体行动建议

### 高优先级

1. **Phase Transition 风险缓解**
   - 实现 r_thres ~ 1/M^(α+1) 的检测逻辑
   - 在 pipeline 中验证 proxy 与 target 是否处于同一相
   - 如果跨相，考虑使用 Apple scaling law 外推而非 proxy 信号

2. **Model Merging 替代方案评估**
   - 参考 DeMix 实现: 训练 7 个 domain expert + 加权合并
   - 对比 QuaDMix proxy 实验的成本与精度
   - 评估 DeMix Corpora (22T tokens) 是否可直接使用

### 中优先级

3. **Scaling Law 函数拟合**
   - 将 LightGBM 黑盒替换为 Apple 的参数化 scaling law
   - Additive law 优先: 参数少、拟合快、最优配比与 scale 无关
   - 仅需 10-20 组 run 即可拟合

4. **CKM 策略实现**
   - 在 Eq.3 sigmoid 采样前，对高质量数据做紧凑改写
   - 预期提升低配比场景下的知识获取效率

### 低优先级

5. **OpenHermes Scaling Law**
   - 拟合 OpenHermes 的 scaling law 并优化配比
   - 与 QuaDMix 当前用 OpenHermes 做验证集的方法对比

6. **多模态扩展准备**
   - Apple 的 scaling law 已在 NMM/LVM 上验证
   - 如果 QuaDMix 扩展到多模态，可直接复用框架
